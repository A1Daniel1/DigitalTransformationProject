# TDSE Project - Digital Transformation

Machine learning-based satellite image analysis for detecting illegal activities in remote areas.

## Authors

- Juan Pablo Vélez Muñoz
- Luiza Mariana Gonzalez Veloza
- Daniel Alexander Ahumada León

## Overview

Detecting illegal activities (deforestation, illegal mining, unauthorized land use) in remote areas is difficult due to limited physical access and the sheer volume of satellite imagery. This project uses machine learning to automatically analyze satellite images, identify suspicious patterns, and flag areas potentially affected by illegal activity for further investigation.
